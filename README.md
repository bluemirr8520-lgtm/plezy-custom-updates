# Plezy Custom Updates

Verified mobile and Android TV releases for the custom Plezy build.

Each release publishes:

- `plezy-mobile-tv-custom.apk`
- `plezy-mobile-tv-custom.apk.sha256`
- `plezy-update.json`

The app installs an update only after validating its package name, version
code, file size, SHA-256 digest, signing certificate, SDK level, and device
ABI.
